Student Result Management System


Description:
The Student Result Management System is a mini project developed in C programming language.
It is a console-based application that calculates and displays a student’s academic result based on marks obtained in five subjects.

Objective: 
1. Take student name and roll number
2. Accept marks of five subjects
3. Calculate total marks and percentage
4. Display grade
5. Show pass or fail status
6. Display a distinction message for students scoring 70% or above

Features:
Simple and user-friendly interface
Automatic result calculation
Grade and result evaluation
Distinction message for high scorers

Grading System:
Percentage	Grade
90 – 100	A+
80 – 89	A
70 – 79	B
60 – 69	C
40 – 59	D
Below 33	F

Result Rules:
Student must score 33 or more in each subject to pass
Failing in any one subject results in Fail
Distinction is awarded for 70% and above
